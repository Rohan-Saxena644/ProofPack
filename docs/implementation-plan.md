# Implementation plan

1. Create a typed SQLite store with transactional claims, leases, attempts, events, assertion ledger, and artifact records. Build two isolated LaunchDesk instances with hashed credentials and server sessions.
2. Implement a bounded Playwright executor, fresh contexts, origin enforcement, durable evidence, cancellation, and truthful terminal outcomes.
3. Add Zod-validated planning and observation-grounded decisions through fixture and replaceable live adapters.
4. Build a responsive Next.js dashboard with new runs, polling, history, and live run details.
5. Generate deterministic Markdown and self-contained HTML reports and serve evidence and traces safely.
6. Verify real browser success, deliberate failure, blocked targets, malformed models, cancellation, crash recovery, and fresh-session persistence. Document actual outcomes and limitations.

Commit at meaningful milestones. No public deployment or challenge submission.
