Manual checklist:

- Start a timer before registration.
- Use a fresh synthetic account and unique project name.
- Create the project and confirm it appears.
- Log out, discard the browser context (or close the profile and start a truly fresh one), then log in.
- Confirm the project is present or absent.
- Capture the relevant screenshots and write a short evidence report.
- Stop the timer once the report is ready to share.

ProofPack checklist:

- Record initial installation/model setup separately.
- Start a timer before entering/loading the brief.
- Run the same expected outcomes; include time spent resolving configuration or blockers.
- Review the ledger and screenshots, then export the report.
- Stop the timer once the evidence is ready to share.
- Record model mode/provider and usage if available; do not infer cost from missing usage.

Measured time saved = manual elapsed − ProofPack elapsed.  
Measured human actions saved = manual actions − ProofPack actions.
